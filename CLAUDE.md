# WebTools (форк deathnemo) — правила для Claude

Проект ведётся с нескольких компьютеров. Перед первой правкой в сеансе — и всегда, когда работа продолжается на другом компьютере:

1. Загрузить навык `obshchie-pravila-proektov` — общие правила: всё на русском, существующее правим на месте, оформление — тёмная тема «Графит».
2. Прочитать `docs/tunewizard-journal.md` целиком: раздел 1 — что перенести на этот компьютер, 2 — цель и рамки, 4 — состояние веток, 7 — соглашения, 8 — грабли.
3. Сверить git с журналом: `git fetch origin`; новую работу начинать от `origin/main` — локальный `main` может отставать.

Только потом править. Главное, что нельзя нарушить и до чтения:

- В upstream ArduPilot ничего не отправлять. PR — только `gh pr create --repo deathnemo/WebTools --base main`; ссылки GitHub `pull/new/...` не давать — для форка они могут целиться в ArduPilot.
- Файлы ArduPilot (пришедшие из upstream) менять минимально, каждый изменённый — в раздел 6 журнала.
- В `main` не пушить и не сливать: сливает пользователь.
- После законченной задачи — обновить журнал по его разделу 9.
