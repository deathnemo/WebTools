# Скрипты исследования этапа 10

Разовые скрипты, по которым посчитаны числа дизайна этапа 10 (`../2026-11-16-tune-wizard-stage10-design.md`). Мастер их не использует, в проверки (`npm test`, браузерные тесты) они не входят. Сохранены, чтобы числа разделов 2 и 11 дизайна можно было пересчитать.

- `initial/` — первый разбор четвёртого лога (16.11.2026):
  - `facts.mjs` — аппарат, режимы, частоты сообщений, параметры, проверки шага 0, отличия параметров от второго лога и `1.param`;
  - `run_wizard.cjs` — прогон мастера в Chrome через Playwright (шаги 0–4, интервал по умолчанию и участок ACRO), итог — `result_log4.json`;
  - `research.cjs` — проверка (б) по половинам, четвертям и блокам, суррогаты, цепочка шага 4;
  - `synth.cjs` — суррогаты на синтетике тестов шага 4: без смены объекта и со сменой K ±25 %;
  - `precision.cjs`, `precision2.cjs`, `precision3.cjs` — погрешность метрик по суррогатам и устойчивость исходов к зерну;
  - `cross.mjs` — связь целей осей.
- `task1/` — калибровка задачи 1 (раздел 11 дизайна): `lib.cjs` — общий код, остальные — по шагам поручения; выводы — `*.txt` рядом.

Запуск — из любой папки: `node <скрипт> "C:/Users/user/WebTools" [аргументы]`, аргументы — в шапке скрипта. Нужны подмодули (`modules/JsDataflashParser`, `modules/fft.js`), `node_modules` (Playwright — только для `run_wizard.cjs`) и логи в `TuneWizard/logs/`; путь к логу — аргументом.
