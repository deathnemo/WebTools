# Мастер настройки — этап 6: иконка и ссылка на главной (дизайн)

Дата: 28.10.2026. Статус: утверждён в обсуждении. Основа — `2026-10-23-tune-wizard-design.md` (раздел 6, этап 6 «Readme, иконка, ссылка на лендинге»). Readme мастера ведётся с этапа 1, на этом этапе только дополняется.

## 1. Решения пользователя (28.10.2026)

- **Ссылка — на главной странице WebTools (`index.html`), сразу после PID Review.** Мастер объединяет FilterReview и PIDReview, поэтому стоит рядом с ними. Страница — файл ArduPilot: если ArduPilot поправит это же место, при подтягивании upstream будет небольшой конфликт, он решается вручную.
- **Иконка — снимок экрана, как у соседних инструментов:** полоса шагов «Шаг 0 … Шаг 5» и под ней спектр шага 2.
- Подпись на русском (общие правила проектов: новое — на русском), остальная главная не меняется.

## 2. Иконка

- Файл `images/TuneWizard_Icon.png`, ширина 400 px (на главной показывается в 200 px, как соседние; двойная плотность — для чётких экранов).
- Делает её скрипт `tests/tunewizard-icon.cjs` (`npm run tunewizard:icon`): Chrome (`CHROME_PATH`), локальный сервер и тестовый лог — как в `tests/tunewizard-browser.cjs`; загрузить лог, открыть шаг 2, снять область от полосы шагов до низа графика `Spectrum2`, уменьшить до 400 px по ширине через canvas в странице и записать PNG.
- Скрипт запускается вручную, только чтобы обновить иконку; файл коммитится. В обычный браузерный тест не входит — иначе каждый прогон менял бы картинку.
- Тема — тёмная «Графит», как у мастера.

## 3. Ссылка на главной

Новая строка таблицы `index.html` после строки PID Review, разметка как у соседей:

```html
  <tr>
    <td>
      <a href="./TuneWizard" style="margin: 20px; display: inline-block;"><img src="images/TuneWizard_Icon.png" style="width:200px"></a>
    </td>
    <td lang="ru" style="text-align:left; vertical-align:top; max-width:960px;">
      <h2>Мастер настройки</h2>
      Пошаговая настройка Copter по одному логу: проверка лога, спектр гироскопов, гармонический notch, низкочастотные фильтры, PID по осям и сводка с файлом .param. Объединяет расчёты FilterReview и PIDReview, предлагает значения с прогнозом эффекта и помнит прошлый проход аппарата.
    </td>
  </tr>
```

`lang="ru"` — язык ячейки для браузера и экранного диктора. Больше на главной ничего не меняется.

## 4. Проверки

- Браузерный тест: открыть главную, найти ссылку `./TuneWizard`, картинка `images/TuneWizard_Icon.png` загрузилась (`naturalWidth > 0`), переход по ссылке — заголовок страницы «Мастер настройки».
- `npm run lint` (главная — HTML-страница под ESLint), `npm test`.
