# Мастер настройки — этап 8: запуск на Windows двойным кликом (дизайн)

Дата: 30.10.2026. Статус: утверждён пользователем 30.10.2026 (вместе с предложениями раздела 9). Проверено до утверждения: `TcpListener` PowerShell 5.1 без прав администратора слушает `127.0.0.1` и отдаёт `text/javascript`.

Повод: пользователь хочет папку, из которой мастер запускается двойным кликом, и раздавать её другим пилотам — без репозитория и без Python. Открыть `TuneWizard/index.html` с диска нельзя: парсер логов (`modules/JsDataflashParser/parser.js`) — ES-модуль, а Chrome не грузит модули и `fetch` (описания параметров `FilterReview/params.json`) со страницы `file://`. Нужен локальный сервер.

## 1. Решения пользователя (30.10.2026)

- **Запуск — `.cmd` и сервер на PowerShell**, без Python и без своего `.exe`: PowerShell есть в каждой Windows 10/11, предупреждения SmartScreen о неподписанной программе нет.
- **Кто пользуется:** пользователь и другие пилоты — поэтому переносная папка, собираемая из репозитория.
- **FilterReview и PIDReview — в папке:** кнопки «Открыть в …» работают и без интернета; инструменты копируются как есть.
- **Раздача — zip на компьютере пользователя**, отправляет он сам; в git и на GitHub архив не попадает.
- **Двойной клик открывает сразу мастер** — `http://127.0.0.1:8000/TuneWizard/`.

## 2. Что видит пользователь

- **В репозитории:** `Мастер настройки.cmd` в корне — двойной клик открывает мастер из рабочей копии (вместо `python -m http.server` и F5).
- **Переносная папка** `Мастер настройки <дата> <коммит>/`: `Мастер настройки.cmd`, `Прочитай меня.txt`, служебные папки (`TuneWizard/`, `Libraries/`, `modules/…`, `FilterReview/`, `PIDReview/`, `images/`). И zip того же имени.
- **Окно консоли** пока мастер работает: «Мастер настройки открыт в браузере: http://127.0.0.1:8000/TuneWizard/ … Чтобы остановить — закройте это окно». Закрыли окно — сервер остановлен, открытая вкладка перестаёт загружать новые файлы (уже загруженная страница работает до перезагрузки).
- **Повторный двойной клик**, когда сервер уже работает (этот же или `python -m http.server` из VS Code на том же порту и с мастером) — просто открывается вкладка, второй сервер не поднимается.
- **Порт 8000 занят чужой программой** — сообщение в консоли «порт 8000 занят другой программой — закройте её»; другой порт не берётся: память прохода привязана к адресу страницы (`http://127.0.0.1:8000`), на другом порту прошлые проходы не видны.
- **Браузер** — тот, что в Windows по умолчанию; в «Прочитай меня» — «нужен Chrome или Edge» (мастер проверяется в Chrome; Edge — тот же движок).

## 3. Сервер `TuneWizard/windows/serve.ps1`

- PowerShell 5.1, файл в UTF-8 **с BOM** (без BOM 5.1 читает русский текст как ANSI).
- `System.Net.Sockets.TcpListener` на `127.0.0.1:8000` — без прав администратора (в отличие от `HttpListener`, которому для адреса нужен `netsh http add urlacl`) и без окна брандмауэра (только петлевой адрес).
- Корень — параметр `-Root` (по умолчанию — папка на два уровня выше скрипта: корень репозитория или переносной папки). Отдаются только файлы внутри корня: путь нормализуется, `..`, абсолютные пути и выход за корень — 403; нет файла — 404; папка — её `index.html`, без косой черты в конце — 301 на адрес с ней (как у `http.server`: иначе относительные ссылки страницы сломаются).
- Методы GET и HEAD; ответ — `HTTP/1.1`, `Content-Type`, `Content-Length`, `Cache-Control: no-cache`, `Connection: close`; запросы по одному (на петлевом адресе ~60 файлов страницы, в том числе Plotly 3.5 МБ, грузятся за доли секунды).
- Типы: `.html` `text/html; charset=utf-8`, `.js`/`.mjs` `text/javascript; charset=utf-8` (обязательно для ES-модуля парсера), `.css`, `.json` `application/json`, `.png`, `.ico`, `.svg`, `.map`, `.param`/`.txt` `text/plain`, прочее — `application/octet-stream`.
- Старт: если порт свободен — слушать и открыть браузер (`Start-Process` с адресом мастера); если занят — запрос `GET /TuneWizard/` на `127.0.0.1:8000`: ответ — страница мастера (`<title>Мастер настройки`) → только открыть браузер и выйти; иначе — сообщение о чужой программе, «нажмите любую клавишу» и выход.
- Ошибка одного запроса не роняет сервер (перехват, ответ 500, строка в консоли). Журнал запросов в консоль не пишется (только старт, адрес, ошибки).

## 4. Запуск `Мастер настройки.cmd`

```
@echo off
powershell -NoProfile -ExecutionPolicy Bypass -File "%~dp0TuneWizard\windows\serve.ps1" -Root "%~dp0."
```

- `-ExecutionPolicy Bypass` — только для этого запуска, политика системы не меняется.
- Текст в `.cmd` — латиница (кодовая страница консоли не важна); русские сообщения пишет `serve.ps1`.
- Один и тот же `.cmd` — в корне репозитория и в корне переносной папки.

## 5. Сборка переносной папки

- Скрипт `tests/tunewizard-portable.cjs`, `npm run tunewizard:portable` (как скрипт иконки — в `tests/`, вручную, в обычные проверки не входит).
- Состав — по тегам `<script>`/`<link>` и `import(`/`fetch(` страниц, проверенный списком в скрипте:
  - `TuneWizard/` без `logs/`;
  - `Libraries/` — только файлы, на которые ссылаются мастер, FilterReview и PIDReview;
  - `modules/JsDataflashParser/parser.js`, `modules/plotly.js/dist/plotly.min.js`, `modules/fft.js/dist/fft.js`, `modules/build/floating-ui/dist/umd/popper.min.js`, `modules/build/tippyjs/dist/tippy-bundle.umd.min.js`;
  - `FilterReview/` (с `params.json` — описания параметров мастера), `PIDReview/`;
  - `images/` — только нужные страницам картинки;
  - `Мастер настройки.cmd`, `Прочитай меня.txt` (генерируется: как запустить, «Запустить?» Windows при первом запуске архива из интернета, закрыть окно — остановить, Chrome/Edge, память — в браузере по адресу `127.0.0.1:8000`, версия и дата).
  Ориентир — около 6 МБ.
- Скрипт после копирования проверяет, что у каждого `src`/`href`/`import(`/`fetch(` трёх страниц есть файл в папке — иначе ошибка сборки (защита от «забыли новый файл»).
- Выход — `dist/Мастер настройки <ГГГГ-ММ-ДД> <коммит>/` и `.zip` рядом (`Compress-Archive` через PowerShell); `dist/` — в `.gitignore`. Незакоммиченные изменения — предупреждение в выводе и пометка «+изменения» в версии.

## 9а. Уточнено при реализации (ревью задач 1–2)

- **`.cmd`:** не только латиница — UTF-8 без BOM, русские сообщения после `chcp 65001` (проверено по экрану консоли); нет рядом `TuneWizard\windows\serve.ps1` (запуск прямо из zip) — «распакуйте весь архив», `pause`; сбой PowerShell — `pause`; аргументы передаются дальше (`%*`).
- **Коды выхода `serve.ps1`:** 0 — сервер отработал или на порту уже мастер этой папки (открыта вкладка); 2 — отказ: порт занят чужой программой или мастером **другой папки** (заголовок `X-TuneWizard-Root` с корнем — старая версия папки не откроется молча); 1 — сбой.
- **«Порт занят»** — пробным подключением перед `Start()`: Windows даёт занять `127.0.0.1:порт`, когда другая программа слушает `0.0.0.0`/`::` (так `python -m http.server` без `--bind`).
- **Безопасность сервера:** проверка `Host` (`127.0.0.1:порт` / `localhost:порт`, иначе 403 — защита от DNS rebinding: в корне репозитория логи пилота и `.git`); `Location` 301 — из нормализованных сегментов (был открытый редирект `//…`); 403 на имена устройств и `::$DATA`; `/` без корневого `index.html` → 301 на `/TuneWizard/`; 405/400/431; ожидание соединений через `Socket.Select` (пустые соединения Chrome).
- **Архив:** `ZipFile.CreateFromDirectory` с `UseBackslash = false` (а не `Compress-Archive`: тот пишет `\` и падает на `[ ]` в пути), файлы — в корне архива (штатное «Извлечь все» иначе даёт папку в папке). Размер — 74 файла, 5.3 МБ, zip 1.6 МБ.
- **Защиты сборки:** папка `logs` исключается без учёта регистра, `.bin` и игнорируемое git в составе — ошибка; папка выхода — по настоящему пути, внутри репозитория вне `dist/` — отказ; `.gitignore` — `/dist/` (шаблон `dist/` прятал upstream `modules/build/*/dist/`), `'dist/**'` в ignores ESLint.
- **Кнопки FilterReview/PIDReview** на невключённые инструменты (Hardware Report, MAGFit, FilterTool) — не добавлять, описать в «Прочитай меня» (решение пользователя 30.10.2026).
